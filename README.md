# 🎓 하루학점 — Daily GPA Planner

종이 플래너의 하루 실천도를 **대학교 학점(A+~F, 4.5 만점 GPA)** 으로 환산해주는 1인용 웹앱.
기록의 원본은 플래너, 여기는 채점만. 빌드 없이 `index.html` 한 파일, GitHub Pages 호스팅.

**앱**: https://jin-artlw.github.io/planner-gpa/

## 채점 과목

- **기상 / 수면**: 계획한 기상·수면 성공/실패 (탭 한 번)
- **일정 · 투두 · 식단 · 운동 · NOT TO-DO**: ＋/− 로 그날의 개수를 정하고, 지킨 개수만큼 번호 탭
- 개수 0인 과목은 그날 채점에서 제외 → 하루마다 과목 수가 달라도 됨

## 채점 방식 (예측 불가)

- 과목별 달성률에 **날짜별로 바뀌는 비공개 가중치(0.6~1.5배)** 와 **난이도 커브**를 적용
- 날짜가 시드라서 같은 날은 언제 계산해도 같은 점수
- 전부 지키면 언제나 A+. 그 외에는 계산해볼 생각 말 것 🤫
- 등급: 95↑ A+(4.5), 90 A0, 85 B+, 80 B0, 75 C+, 70 C0, 65 D+, 60 D0, 미만 F
- 월 평점 = 채점된 날들의 평점 평균 (4.5 만점)

## 저장 방식

**기본: 이 기기에만 저장** (localStorage). 토큰도 GitHub도 필요 없음.

- 📱 **홈 화면에 추가해서 쓰는 걸 전제로 함** — 사파리 공유 → "홈 화면에 추가".
  앱 전용 저장공간이 생겨 시크릿 모드와 무관하게 기록이 유지된다.
- ⚠️ 시크릿 모드 탭에서 직접 쓰면 탭을 닫을 때 기록이 사라진다.
- 백업: 성적표/설정 탭에서 월별 `.md`(사람이 읽는 성적표 + 복원용 데이터 블록) 또는
  전체 `.json` 내려받기 → 설정 탭에서 다시 가져오기 가능.

### GitHub 동기화 (선택)

여러 기기를 쓰거나 기록을 GitHub에 남기고 싶을 때만: 비공개 저장소를 만들고
Fine-grained 토큰(해당 저장소만, Contents Read/Write)을 설정 탭에 연결하면
수정 4초 뒤 `data/YYYY-MM.md`로 자동 커밋된다. 날짜별 최신 수정본 기준으로 병합.
브라우저에서 GitHub에 쓰기는 인증이 필수라서, 동기화를 켜는 순간부터는 토큰이 필요하다.
