# 🎓 하루학점 — Daily GPA Planner

종이 플래너의 하루 실천도를 **대학교 학점(A+~F, 4.5 만점 GPA)** 으로 환산해주는 1인용 웹앱.
기록의 원본은 플래너, 여기는 채점만. 빌드 없이 `index.html` 한 파일, GitHub Pages 호스팅.

**앱**: https://jin-artlw.github.io/planner-gpa/
**데이터 저장소(비공개)**: https://github.com/JIN-ARTLW/planner-data

## 사용법 (시크릿모드 기준)

1. 앱 열기 → 맨 위 **🔐 금고 암호** 입력 → 자동 연동 + 이번 달·지난달 기록 자동 불러오기
2. 기록: 기상/수면은 성공·실패 탭, 과목(일정·투두·식단·운동·하지 말 것)은
   ＋/− 로 오늘의 개수를 정하고 지킨 개수만큼 번호 탭
3. 저장은 전자동 — 입력 1.5초 뒤 자동 커밋, 탭을 닫는 순간에도 즉시 저장
4. 성적표 탭: 달력에 일별 등급, 월 GPA, 과목별 달성률, **월간 성적표 이미지(PNG) 저장**

## 채점 (예측 불허)

- 날짜를 시드로 한 **비공개 가중치**(과목 간 최대 7배) × **최약 과목 페널티** ×
  **난이도 커브** + **등급컷 매일 0~3점 상향**. 같은 날짜는 언제 계산해도 같은 점수
- 모든 항 단조증가 — 더 지켰는데 점수가 내려가는 일은 없음
- **전부 지키면 무조건 A+(4.5)**. 이것만 보장
- 기본 등급컷: 95↑ A+(4.5), 90 A0, 85 B+, 80 B0, 75 C+, 70 C0, 65 D+, 60 D0, 미만 F
- 월 평점 = 채점된 날들의 평점 평균
