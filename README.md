# 🎓 하루학점 — Daily GPA Planner

종이 플래너의 하루 실천도를 **대학교 학점(A+~F, 4.5 만점 GPA)** 으로 환산해주는 1인용 웹앱.
기록의 원본은 플래너, 여기는 채점만. 빌드 없이 `index.html` 한 파일, GitHub Pages 호스팅.

**앱**: https://jin-artlw.github.io/planner-gpa/

## 채점 과목

- **기상 / 수면**: 계획한 기상·수면 성공/실패 (탭 한 번)
- **일정 · 투두 · 식단 · 운동 · 하지 말 것**: ＋/− 로 그날의 개수를 정하고, 지킨 개수만큼 번호 탭
- 개수 0인 과목은 그날 채점에서 제외 → 하루마다 과목 수가 달라도 됨

## 채점 방식 (예측 불허)

- **날마다 뒤바뀌는 비공개 가중치**(과목 간 최대 7배 차) × **그날의 최약 과목 페널티**
  × **난이도 커브**(1.1~1.8제곱) 로 산출하고, **등급컷도 매일 0~3점 몰래 상향**
- 날짜가 시드라서 같은 날은 언제 계산해도 같은 점수. 계산으로는 못 맞힌다
- 모든 항은 단조증가 — 더 지켰는데 점수가 내려가는 일은 없음
- **전부 지키면 무조건 A+(4.5).** 이것만 보장
- 기본 등급컷: 95↑ A+(4.5), 90 A0, 85 B+, 80 B0, 75 C+, 70 C0, 65 D+, 60 D0, 미만 F
- 월 평점 = 채점된 날들의 평점 평균 (4.5 만점)
- 성적표 탭에서 **월간 달력 성적표 이미지(PNG)** 로 내려받기 가능

## 저장 방식

**기본: 이 기기에만 저장** (localStorage). 토큰도 GitHub도 필요 없음.
⚠️ 단, 시크릿 모드는 탭을 닫으면 기기 기록이 사라진다.

### 시크릿 모드 전용 사용법 (한 번만 세팅, 이후 관리 제로)

1. 비공개 데이터 저장소(`JIN-ARTLW/planner-data`) + Fine-grained 토큰
   (Repository access는 그 저장소 1개만, Permissions → Contents: Read and write, 만료 1년)
2. 앱 설정 탭 → 토큰 붙여넣기 → 연결 테스트 → **"시크릿모드용 북마크 URL 복사"** → 북마크 저장
3. 이후엔 그 북마크로만 열면 끝:
   - 열 때 이번 달·지난달 기록 자동 불러오기
   - 입력 1.5초 뒤 자동 커밋 + **탭을 닫거나 화면을 벗어나는 순간에도 즉시 저장**(keepalive)
   - URL 해시(`#t=…`)는 서버로 전송되지 않음. 토큰이 만료되는 1년 뒤에만 갱신하면 됨

수정은 `data/YYYY-MM.md`로 커밋되며(사람이 읽는 월간 성적표 + 복원용 데이터 블록),
여러 기기에서 써도 날짜별 최신 수정본 기준으로 병합된다.
백업: 성적표/설정 탭에서 월별 `.md` 또는 전체 `.json` 내려받기 → 설정 탭에서 복원.
