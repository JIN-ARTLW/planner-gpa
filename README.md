# 🎓 하루학점 — Daily GPA Planner

종이 플래너의 하루 실천도를 **대학교 학점(A+~F, 4.5 만점 GPA)** 으로 환산해주는 1인용 웹앱.
기록의 원본은 플래너, 여기는 채점만. 빌드 없이 `index.html` 한 파일, GitHub Pages 호스팅.

**앱**: https://jin-artlw.github.io/planner-gpa/

## 채점 과목

- **기상 / 수면**: 계획한 기상·수면 성공/실패 (탭 한 번)
- **일정 · 투두 · 식단 · 운동 · NOT TO-DO**: ＋/− 로 그날의 개수를 정하고, 지킨 개수만큼 번호 탭
- 개수 0인 과목은 그날 채점에서 제외 → 하루마다 과목 수가 달라도 됨

## 채점 방식 (예측 불가)

- 과목별 달성률에 **날짜별로 바뀌는 비공개 가중치(0.6~1.5배)** 와 **난이도 커브**를 적용
- 날짜가 시드라서 같은 날은 어느 기기서든 같은 점수 (동기화 안전)
- 전부 지키면 언제나 A+. 그 외에는 계산해볼 생각 말 것 🤫
- 등급: 95↑ A+(4.5), 90 A0, 85 B+, 80 B0, 75 C+, 70 C0, 65 D+, 60 D0, 미만 F
- 월 평점 = 채점된 날들의 평점 평균 (4.5 만점)

## 저장 구조

- 입력 즉시 localStorage 저장 + 4초 뒤 GitHub 비공개 저장소(`JIN-ARTLW/planner-data`)에
  `data/YYYY-MM.md` 자동 커밋 (사람이 읽는 월간 성적표 + 하단 복원용 데이터 블록)
- 여러 기기 사용 시 날짜별 최신 수정본으로 병합
- 앱을 열면 이번 달·지난달 기록을 자동으로 불러옴

## 시크릿 모드에서 쓰기

시크릿 모드는 localStorage가 매번 사라지므로, 설정 탭 → 토큰 입력 →
**"시크릿모드용 북마크 URL 복사"** 로 `#t=토큰&r=저장소` 가 붙은 주소를 북마크에 저장.
이후엔 그 북마크로 열기만 하면 자동 연결 + 자동 불러오기. (URL 해시는 서버로 전송되지 않음)

토큰: GitHub → Settings → Developer settings → Fine-grained tokens →
Repository access를 `planner-data` 1개만, Permissions → **Contents: Read and write**.
